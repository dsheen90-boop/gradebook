Trimester Dates
These date ranges control which trimester an assignment is automatically filed under, based on its due date — teachers and admins no longer pick a trimester manually when creating an assignment. Changing these and saving will recalculate the trimester on every existing assignment.
Category Weights
How much each kind of work counts toward a student's grade — in the Gradebook, Progress Reports and Report Cards. Weights should add up to 100%. If a student has no graded work in a category yet, that category is skipped and the others are scaled up.
Letter Grade Scale
Minimum percentage for each letter grade. Used everywhere a letter grade is shown, including report cards.
